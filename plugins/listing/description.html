Sends your own character's progress to Rune Advisor, a free planner that suggests what to do next (quests, achievements, levels, gear) and how long it is likely to take for your account, ironman accounts included.

What it does. Once you give it a token, the plugin posts your character's state to https://api.runeadvisor.com, the only address it talks to, so that your planner can read it. It sends the full state once per login and after that only what changed, at most once every few seconds.

What is sent.

  • Your character's display name, experience in each skill, whether you are on a members' world, and its account mode (Ironman, Hardcore Ironman, Group Ironman).

  • Quest and achievement progress: the player variables the game's quests and achievements test.

  • Your own item storage: bank, backpack, worn equipment, money and currency pouches, and the skilling containers (ore box, wood box, herb bag, material storage and the like).

  • Balances and counters shown in the game's own interfaces, such as Slayer points, quest points, penguin points and banked bonus experience.

  • After a game update, the game's own quest and achievement definitions that changed. That is game data, the same for every player.

  • The charges of your active sign of the porter (or Grace of the Elves), read off the number on its buff icon: the game keeps them on the item, which plugins can't read.

  • Only if you allow the optional chat permission: your rested experience (Fort Forinthry) and its cap, which the game tells you only in one of its own chat messages. The plugin reads the game's own messages and keeps just those two numbers; any message with a sender is dropped before anything else is looked at.

What is never read or sent. Anything about other players; chat between players, yours included; the text of any message; where your character is, what you click or which keys you press; your Jagex account, login name or email address.

Nothing is sent until you set it up.

  1. Make an account at https://runeadvisor.com/account/. An account is a random key: no email address, no name, no password.
  2. Make a submit token there and paste it into this plugin's settings (the settings icon on the plugin in the Plugin Hub's Manage tab). The plugin checks the token and says whether it was accepted.
  3. Log in to the game. Removing the token in the settings, or revoking it on the account page, stops all posting, and the account page deletes everything stored.

One token covers the whole computer. The game keeps plugin settings per computer, not per login, so a saved token sends every character played in that game client there, whoever is playing. On a shared computer, tell the others or remove the token when you finish.

Optional. The settings also hold one choice, off unless you turn it on: whether this character's data may be analysed, without names or account details, to improve the planner for everyone. It changes nothing about what is sent.

Permissions

httpAccess

This plugin requests the httpAccess permission for https://api.runeadvisor.com. This permission is used to send the information listed under "What is sent" to that address, where it is stored so that your planner can read it and suggest what to do next. The plugin contacts no other address.

chatAccess (optional)

This plugin asks for the optional chatAccess permission to read one value the game gives only in a chat message: your Fort Forinthry rested experience ("Working in the fort increases your rested XP (3/1500)"). A message that has a sender (anything written by a player, you included) is dropped before its type or text is read; of the game's own messages, only those matching that wording are used, and only the two numbers are kept and sent. No message text is stored or sent. Without this permission the plugin works the same, and the planner uses the rested experience you enter yourself.

Data Protection

This plugin uses the following information: the display name of the character that is logged in; its experience in each skill; whether it is on a members' world; the player variables that the game's quests and achievements test; a written-out list of other player variables (currencies, storages kept in variables, collection log entries, tool belt, bonus experience); and the item ids and quantities in the player's own item storage; the charges shown on the sign of the porter's buff icon; and, with the optional chat permission, your rested experience and its cap from the game's own chat message. It reads nothing about other players and no chat between players.

This information is transmitted to https://api.runeadvisor.com, a server in the United States, which does not have full or relevant partial UK adequacy status as specified by https://developer.runescape.com/rs/submission/adequacy.html, however, Jagex and the Developer have put in place appropriate safeguards to protect your data. The developer's privacy notice is available at https://runeadvisor.com/privacy/.

This endpoint secures the data by accepting HTTPS only (TLS 1.2 and 1.3), by authenticating every request with a token that is stored on the server only as a hash, by running the service as an isolated, unprivileged process, by limiting requests per address and per token, and by encrypting backups with a key that is not kept on the server. There are no logins, names, email addresses or passwords: an account is a random key. The information can be accessed by you, with a token of your own account, through the planner or the account page; and by the developer, who operates the server, only where running the service requires it. With your consent, given per character and off by default, a character's data may also be analysed without names or account details to improve the planner. All data rights requests should be submitted to the email address given above; you can also delete a character or the whole account yourself at https://runeadvisor.com/account/.

Game information is not stored by the plugin between sessions, except the last state the server accepted for each character, which is kept so that only changes need sending. Plugin settings (the token and the posting interval the server asked for) are stored within the plugin between sessions. The client keeps these per computer, not per login: see "One token covers the whole computer" above.
