Your account

Paste an account key to see the account, manage its tokens or delete its data. The key stays in this page's memory only: it is not saved in the browser, not put in the address bar, and sent nowhere except to api.runeadvisor.com. Closing or reloading the page forgets it.

Open an account

Making a new account runs a check that you are not a bot, provided by Cloudflare: only then does this page contact Cloudflare. Opening an existing account never does.

This is your new account key. It is shown once and cannot be recovered. Save it somewhere safe (a password manager) before going on.

Opened with a plugin's token

This is a plugin's token, not an account key. It cannot manage the account, but it can show and delete what it posted. To get the token out of your plugin, use "Show the saved token" in the plugin's settings.

Web planner

The planner runs in this browser tab on the characters stored under this account. Opening it makes a read token for this tab; closing the tab forgets it, so the next visit starts here with the account key.
