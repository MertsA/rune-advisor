Rune Advisor

A planning helper for RuneScape 3. It reads your own character's progress and works out what is worth doing next: which quests, achievements, levels, boss logs and gear are closest, what each one still needs, and how long it is likely to take for your account, ironman accounts included.

Not released yet. The in-game plugin is with Jagex for review and is not in the Plugin Hub until that review passes. The planner has no installer or download yet. This site describes how it works so that the description exists before the software does.

How it fits together

  • The planner is a program that runs on your own computer (Windows and Linux). The planning happens there, not on a server.
  • The plugin is a small in-game plugin for the official RuneScape plugin system. It sends your own character's state (skills, quest and achievement progress, your item storage) to the Rune Advisor API, so the planner can read it. Exactly what is sent.
  • The API at api.runeadvisor.com keeps the latest state of each character and hands it to the planner that holds the right token. There is no login: an account is a random key, with no email address and no name.
