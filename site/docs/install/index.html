Installing

Not possible yet. Neither the plugin nor the planner can be installed today. This page says what the steps will be, so they can be checked against what is finally released.

What will be needed

  • RuneScape 3 with the official plugin system, and the Rune Advisor Export plugin from the Plugin Hub. Not available yet: the plugin is with Jagex for review.
  • The planner for Windows or Linux. macOS is not planned for the first release. Not available: there is no installer or download yet.

The steps, once both exist

  1. Make an account and keep its key (accounts, keys and tokens).
  2. Make a submit token and paste it into the plugin's settings (the settings icon on the plugin in the Plugin Hub's Manage tab). The plugin checks the token with the API and says whether it was accepted.
  3. Make a read token and give it to the planner.
  4. Log in to the game once so the plugin can post your character.

Steps 1 to 3 already work on the account page; the planner is meant to do them for you when it gets its own window.

Without the plugin

The planner can work from public data alone (the hiscores and the Adventurer's Log), with less detail: it then knows your levels and finished quests, but not your bank, achievements or currencies.
